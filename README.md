A clean, editorial-style personal portfolio for **Shalini Jagili**, a B.Tech 2nd-year student in **Artificial Intelligence & Machine Learning** at **Sri Sai Engineering College, Rayachoty, Andhra Pradesh**.

  - Sri Sai Engineering College, Rayachoty

- **Diploma**
  - Sri Sai Institute of Technology and Science, Rayachoty
- **School**
  - AP Model School, Rayachoty

## Design

This site intentionally avoids the usual dark/neon developer-portfolio layout. It uses:

- Mostly white/off-white editorial layout
- Asymmetric grid
- Large typography
- Thin archive-style numbering
- Cobalt blue + coral accent colors
- Campus photo archive
- Responsive mobile layout
- Small JavaScript reveal animation
- No framework and no build step

## Run locally

Just open `index.html` in a browser.

## Publish with GitHub Pages

1. Create a new GitHub repository, for example `shalini-jagili-portfolio`.
2. Upload **all files and the `assets` folder**.
3. Go to **Settings → Pages**.
4. Under the build/deployment section, select **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder.
6. Save.
7. GitHub will provide the live website URL.

### Important

Do not upload only `index.html`. The CSS, JavaScript, and `assets` folder are required for the design and campus photos to work.

## Editing later

The easiest place to edit personal information is `index.html`.

- Change the education text inside the education cards.
- Add real skills/projects when available.
- Add GitHub/LinkedIn links when those URLs are available.
- Replace the three images inside `assets/` if better photographs are available.

No PHP, database, Node.js, or server is required.
